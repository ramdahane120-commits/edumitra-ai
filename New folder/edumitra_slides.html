TECHNICAL APPROACH Microservices & Retrieval-Augmented Generation (RAG) Architecture
TEAM: ENDEAVOURS
🛠️ Complete Tech Stack Credentials
React.js (Frontend PWA) Python FastAPI Node.js Express Llama-3 8B LLM ChromaDB Vector Store PostgreSQL Redis Caching Bhashini Voice STT/TTS Docker & K8s
01
User Access & Multilingual Layer
Responsive React.js PWA + WhatsApp API integration. Integrates **Bhashini Indic API** for real-time speech recognition (STT) and voice synthesis (TTS) in Hindi & English.
02
AI & RAG Intelligence Engine
Python FastAPI microservice utilizing **LangChain RAG pipeline** and **Llama-3 8B**. Queries vector embeddings of official REAP seat matrices and DTE handbooks stored in **ChromaDB**.
03
Relational Data & Cutoff Engine
**PostgreSQL** manages structured datasets for 150+ Rajasthan engineering & polytechnic colleges, previous year cutoffs, fees, placement stats, and hostel availability.
04
Zero Hallucination & Citation Engine
Strict RAG prompt grounding ensures AI responses are 100% cited from official DTE Rajasthan PDFs, eliminating misinformation in critical admission decisions.
